# No Wood Water Damage

Wood, hardwood, and timberwood pieces no longer wear from rain, weather, or water exposure by default. Ships are unchanged. Needs client and dedicated server.

## Configuration

Two settings are written to `BepInEx/config/cjayride.NoWoodWaterDamage.cfg` on first launch:

| Setting | Default | Description |
|---|---|---|
| `PreventAllWeatherDamage` | `true` | Protects ALL wood pieces everywhere, not just at the waterline. Disables rain/weather/seasons wear globally. |
| `ProtectAtWaterline` | `true` | Original behavior - protects pieces at or near the water surface only. Useful if you set `PreventAllWeatherDamage` to false. |

Set both to `false` to disable the mod entirely.

See `Package/README.md` for store install notes.
